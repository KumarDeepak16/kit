## Keyboard

| Where | Keys |
| --- | --- |
| Boost dial (focused) | `←` `→` / `↑` `↓` ±5% · `PgUp` `PgDn` ±50% · `Home` 0% · `End` 600% |
| Vault editor | `Enter` save · `Esc` close |
| Drop (popup and full view) | `Enter` send · `Shift`+`Enter` new line · paste or drag files to send them |
| Image viewer | `Esc` close |

## The toolbar buddy

| Buddy | Meaning |
| --- | --- |
| Purple, eyes open | Something is running: a boosted tab or Drop |
| Grey, asleep | Kit is idle and holding nothing open |
